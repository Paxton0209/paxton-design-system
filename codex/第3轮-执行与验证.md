## 任务 A：检查脚本（`product/checks/`）

两个脚本都不依赖设计系统以外的文件；`audit.mjs` 只依赖 Playwright。

**A1 `check-ui.mjs`（静态检查）**

用法：`node check-ui.mjs <文件或目录…> [--config ds-check.json]`，输出 `文件:行:列 规则 说明`，有报错时退出码 1。

| 规则 | 检查内容 |
| --- | --- |
| `color-literal` | CSS 中的 `#hex`、`rgb()`、`hsl()`、颜色关键字（`transparent`、`currentColor`、`inherit` 除外） |
| `raw-length` | `px` 数值，例外：`0`、`1px`、`1.5px`、`2px` 线宽 |
| `radius` | `border-radius` 不是 `var(--ds-radius-*)`、`0`、`50%`、`inherit` |
| `font` | `font-size`、`font-weight`、`font` 不用 `var(--ds-text-*)` 或允许值 400 / 500 |
| `duration` | `transition`、`animation` 的时长不用 `var(--ds-motion-*)`（`0s` 除外） |
| `banned` | `linear-gradient` / `radial-gradient`（媒体遮罩可 ds-allow）、`backdrop-filter`、`inset 0 1px 0` 形式的内高光 |
| `middle-dot` | HTML 文字节点和 JS 字符串里的「·」 |
| `tokens-only` | 引用了 tokens.json 里不存在的 `--ds-*` 变量 |

- 同一行或上一行有 `/* ds-allow: 原因 */` 时跳过，并在结尾汇总全部例外。
- `ds-check.json`：`ignore` 路径、`allowPx`、`tokens` 路径；附一个默认配置。
- 自测：对 `product/components/` 和 `product/gallery.html` 运行，必须零报错（ds-allow 除外）；再造一个故意违规的小文件 `checks/fixtures/bad.css`，确认每条规则都能报出来。

**A2 `audit.mjs`（渲染检查）**

用法：`node audit.mjs --url <地址> [--url …] --out <目录> [--viewports 1440,390] [--themes light,dark]`

- 每个地址、视口、主题各截一张全页图（等字体加载、关闭过渡）。
- 文字对比度：方法同第 2 轮；按 SPEC 第 12 节分组：默认、选中、焦点、错误状态低于 4.5:1 的列为失败；悬停、禁用、加载单列为豁免。
- 圆角：所有可见元素计算后的圆角必须在 {0, 4, 6, 10, 16, 999, 50%} 内。
- 字号与字重：计算后的值必须在 tokens 允许集合内。
- 输出 `audit.json` 和 `audit.md`（摘要、失败项、豁免项、截图列表）；有失败项时退出码 1。
