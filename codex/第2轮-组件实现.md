## 硬规则

1. **不改** `README.md`、`SPEC.md`、`COMPONENTS.md`、`DECISIONS.md`、`tokens/` 和上一级目录的任何文件。规格不清楚或有矛盾时停下，写进 REPORT 的「问题」一节，不自行决定。
2. CSS 里不写颜色、圆角、字号、字重、间距、阴影、时长的数值，全部用 `var(--ds-…)`。只有以下例外可以写数值：`0`、`1px` / `1.5px` / `2px` 线宽、百分比、`999px`、z-index 取 `--ds-z-*`、组件自身的固定尺寸（例如开关 28 × 16、圆点 12），例外处加注释 `/* ds-allow: 原因 */`。
3. 每个伪类状态都有等价的强制状态类（COMPONENTS.md 第 0 节），写在同一条规则里。
4. 不加 COMPONENTS.md 以外的组件、变体、说明文字或装饰。
5. 不用渐变（媒体卡遮罩除外）、毛玻璃、内高光；滑动的选中块不加投影。
6. 字体：引用上一级目录现有的 Inter 文件或系统回退，不新增字体文件。
