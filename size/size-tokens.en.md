# Car Display Size Tokens

[简体中文](size-tokens.md)

This table records the seven `Size` variables migrated to Figma `Library-test`. Each uses the `Value` mode and is measured in pixels. See [SPEC 13.1](../SPEC.md#131-车机hmi组件v01作者验收中) for the general car display guidelines.

| Token | Value (px) | Figma scope | Use |
|---|---:|---|---|
| `cockpit/icon/app-tile` | 54 | `WIDTH_HEIGHT` | Width and height of a Dock app tile |
| `cockpit/radius/tile` | 14 | `CORNER_RADIUS` | Corner radius of a Dock app tile |
| `cockpit/height/panel` | 728 | `WIDTH_HEIGHT` | Cockpit panel height |
| `cockpit/radius/card` | 28 | `CORNER_RADIUS` | Corner radius of cockpit cards and the SR panel |
| `cockpit/line/title` | 36 | `LINE_HEIGHT` | Line height of the `Cockpit/Title` text style |
| `cockpit/type/title` | 28 | `FONT_SIZE` | Font size of the `Cockpit/Title` text style |
| `cockpit/width/panel-sr` | 520 | `WIDTH_HEIGHT` | Width of the narrow SR panel |
