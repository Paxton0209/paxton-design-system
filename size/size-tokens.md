# 车机尺寸 token

[English](size-tokens.en.md)

下表记录迁入 Figma `Library-test` 的七个 `Size` 变量。它们都使用 `Value` 模式，单位为 px。车机通用规范见 [SPEC 13.1](../SPEC.md#131-车机hmi组件v01作者验收中)。

| token | 值（px） | Figma 作用域 | 用途 |
|---|---:|---|---|
| `cockpit/icon/app-tile` | 54 | `WIDTH_HEIGHT` | Dock 应用磁贴的宽和高 |
| `cockpit/radius/tile` | 14 | `CORNER_RADIUS` | Dock 应用磁贴圆角 |
| `cockpit/height/panel` | 728 | `WIDTH_HEIGHT` | 座舱面板高度 |
| `cockpit/radius/card` | 28 | `CORNER_RADIUS` | 座舱卡片与 SR 面板圆角 |
| `cockpit/line/title` | 36 | `LINE_HEIGHT` | `Cockpit/Title` 文字样式的行高 |
| `cockpit/type/title` | 28 | `FONT_SIZE` | `Cockpit/Title` 文字样式的字号 |
| `cockpit/width/panel-sr` | 520 | `WIDTH_HEIGHT` | 窄版 SR 面板宽度 |
